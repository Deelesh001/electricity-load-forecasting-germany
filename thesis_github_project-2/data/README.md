# Data

This directory is intentionally kept free of large source datasets in Git.

## Electricity load

Download the German hourly actual-consumption data from the **SMARD.de Download Center** (Bundesnetzagentur):

https://www.smard.de/en/downloadcenter/download-market-data/?downloadAttributes=%7B%22superCategoryId%22:2,%22subcategoryId%22:5,%22regionId%22:%22DE%22,%22resolution%22:%22hour%22,%22fileType%22:%22CSV%22,%22from%22:1420066800000,%22to%22:1580511599999%7D

The thesis pipeline expects these two files in `data/raw/load/`:

- `Actual_consumption_201501010000_202501010000_Hour.csv`
- `Actual_consumption_202501010000_202601010000_Hour.csv`

They contain the hourly German electricity-load source data used by `notebooks/02_data_preprocessing.ipynb`.

## Weather

Weather data are generated by `notebooks/01_weather_data_collection.ipynb` and written to `data/processed/`.

## Processed data

`notebooks/02_data_preprocessing.ipynb` creates the final combined data and chronological train/validation/test CSV files in `data/processed/`.
